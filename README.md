## 🔐 系統特色與防護架構

1. **嚴謹門禁防護**：
   - 採用前端原生 SHA-256 加密雜湊驗證，確保研習現場專用保護。
   - 所有原始碼、資料檔案與文件皆嚴格杜絕通行碼明文標註。
   - 瀏覽器本機憑證記憶（LocalStorage），登入後重新整理不中斷體驗。

2. **多視角極致操作**：
   - **Padlet 原生看板瀑布流**：水平滾動各個分欄，完整呈現原看板之空間佈局與脈絡。
   - **總覽網格**：響應式排列，平板與手機皆能快速瀏覽。
   - **本機檔案庫**：直覺式表格列出所有 42 項實體教材，一鍵即時下載。

3. **教師研習實用工具箱**：
   - **一鍵複製卡片與提示詞**：每張卡片附帶複製按鈕，點擊即複製並跳出提示。
   - **高清大圖燈箱**：點擊卡片縮圖立即全螢幕放大檢視與儲存。
   - **行動 QR Code 彈窗**：現場學員使用手機/平板直接掃碼取用。
   - **隨身備忘筆記盒**：學員可一邊聽課一邊在右側抽屜記錄靈感與提示詞，自動儲存於本機。
